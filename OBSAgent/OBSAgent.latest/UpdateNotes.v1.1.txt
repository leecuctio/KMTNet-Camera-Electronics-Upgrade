  << ExpStatus in ExpInfo string >>
     CHECK    : Init. or sys.camstatus == CAMSTATUS_CHECK, when script observation is not in progress
     STANDBY  : sys.camstatus==CAMSTATUS_READY, when script observation is not in progress
     WAITING  : sys.camstatus==CAMSTATUS_READY, in preparing Tel during script observation
     CMDED    : sys.camstatus==CAMSTATUS_CHECK, at Go commanded by script observation process
     FLUSH    : sys.camstatus>=CAMSTATUS_PREP_I -- "EXPSTATUS=INITIALIZING"
     EXPOSURE : sys.camstatus>=CAMSTATUS_INT_1  -- "EXPSTATUS=INTEGRATING"
     READOUT  : sys.camstatus>=CAMSTATUS_READ_1 -- "EXPSTATUS=READOUT"
     FINISH   : sys.camstatus>=CAMSTATUS_IDLE_1 -- 1st "Acquisition Complete"
     ERROR    : sys.camstatus<0(CAMSTATUS_CRASHED/DEAD/NC)

  << CamStatus in SysStatus string >>
     NC      : not connected to ICS
     PREP_I  : "EXPSTATUS=INITIALIZING" message from ICS
     PREP_E  : "EXPSTATUS=ERASE" message from ICS
     INT_1   : "EXPSTATUS=INTEGRATING" message from ICS
     INT_2   : "Shutter=Open" message from K.IC
     INT_3   : "Remaining=" message from K.IC
     CLOSING : "Shutter=Closed" message from K.IC
     READ_1  : "EXPSTATUS=READOUT" message from ICS
     READ_2  : 1st "PCTREAD=" message from K.IC
     READ_3  : 2nd "PCTREAD=" message from K.IC
     IDLE_1  : 1st "Acquisition Complete" from each ICs
     IDLE_2  : 4th "Acquisition Complete" from each ICs
     IDLE_3  : "EXPSTATUS=IDLE" message from ICS, only 'GO' command available
     READY   : "Disk Write Complete" message on all ICs
     CHECK   : unknown status
     CRASHED : "Failed to Start acquisition on one or more ICs", 
               or "Failed to initialize one or more ICs",
               or when the status become not IDLE2 or IDLE3.
   * Note
      - 'EXP'/'OBJECT'/'DARK'/'BIAS'/'FLAT'/'PROJID'/'OBSERVER' commands are available only in READY status.
      - CamStatus is forcibly set to 'READY' status 12 seconds after setting to 'IDLE_3' by "EXPSTATUS=IDLE" message.
