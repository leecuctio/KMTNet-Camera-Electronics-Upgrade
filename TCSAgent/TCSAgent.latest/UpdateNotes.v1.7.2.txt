KMTNet TCSAgent v1.6.6 update notes

- updated functions
    - print of catalog data number at 'catalog' command input.
    - more flexible catalog input, refer to pctcs.cat for details
    - TSTAT: LimitStatus was modified with bit masking for simultaneous events.
      <Old version>
        LimitStatus = 0:No / 1:RA / 2:Dec / 3:Horizon / -1:Unknown
      <New version> 
        LimitStatus = 0:No / 1:RA / 2:Dec / 3:RA+Dec / 4:Horizon / 5:RA+Horizon / 
                      6:Dec+Horizon / 7:RA+Dec+Horizon / -1:Unknown
    - TCSSTATUS: LimitStatus Lables are added for simultaneous events.
      <Old version> 
        TCSLIMIT=No/RA/Dec/Horizon/Unknown
      <New version> 
        TCSLIMIT=No/RA/Dec/Horizon/RA+Dec/RA+Horizon/Dec+Horizon/
                  RA+Dec+Horizon/Unknown
     - 'history' command upgrade: last entries display option and entries clearing
       option are now available. (usage: "history" / "history 3" / "history -c" )

- modification/debugging
    - Catalog loading routine improved for more flexible catalog file input
    - Internal code improvement, String lengths, mecro names and constant values were redefined
      to allocated/stack memory problems and to meet condition for using ISIS Lib func
    - Command history fucntion improved with repetitions skip in history addition
    - Readline prompt reset routine improved both in key cmd proc and socket cmd proc
    - Some minor debugging and improvement for message output
    - cmd_tsync() code modified, time setting first before date setting
