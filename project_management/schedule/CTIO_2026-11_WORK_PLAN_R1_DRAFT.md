# CTIO 출장 인원별 업무 분담 최적안 (R1 초안)

작성일: 2026-09-16 | 갱신: 2026-09-16 (온스카이 5개 과업을 중요도 순으로 재배치, 원격지원 2인 반영) | 작성: 이충욱 (PM) | 지위: **R1 초안 — SSO 최적안([SSO_2026-10_WORK_PLAN_R1_DRAFT.md](SSO_2026-10_WORK_PLAN_R1_DRAFT.md)) 형식을 CTIO 일정에 적용**

출장 인원 6인(이충욱·이동주·이용석·차상목·김동진·이상민) 기준. SSO와 달리 **더미 HE박스 교체가 없고**, ICS/AIC/네트워크 이전은 SSO에서 이미 완료되어 있어 신규 이전 작업이 없다. 대신 CTIO에서 **신규 전자부의 첫 온스카이 commissioning**을 수행하므로 온스카이 5박(11-18~22)의 세부 배분이 이 문서의 핵심이다. 공정 기준은 [`sites/CTIO/SITE_PLAN.md`](../sites/CTIO/SITE_PLAN.md), [`SITE_UPGRADE_MILESTONES.md`](SITE_UPGRADE_MILESTONES.md).

김재우(과학 검증)·홍성욱(SW)은 이번 출장 인원에 포함되지 않고 **원격지원**한다 — 김재우는 영상 검토·acceptance 판정, 홍성욱은 초점 모니터링 코드 수정·파이프라인 네트워크 설정의 SW 측 원격 지원을 맡는다.

## 1. 배분 원칙

| 구분 | 원칙 |
| --- | --- |
| 중요도 | **P1** = 카메라 크리티컬 패스(월보드 교체 → 진공·냉각 → 시험관측 → 온스카이 → acceptance). **P2** = P1 선행조건(클린부스, HE박스 탈거, 현지 네트워크·전원 확인). |
| 역할 축 | SSO 최적안의 역할 축을 그대로 승계한다 — 차상목(카메라 크리티컬 패스 리드), 이상민(기계 실무 + 시험관측 리드), 이용석(하드웨어·물류·클린부스), 김동진(네트워크·전산), 이동주(기록 담당 + 시설 지원), 이충욱(총괄 — 브리핑·안전·점검·확인·연락). |
| 온스카이 배분 | 5개 과업(카메라 틸트/회전각 측정·조정, 마운트 모델관측·모델 적용, 초점 모니터링 코드 수정·적용, 타겟 스크립트관측 점검, 파이프라인 네트워크설정)을 **중요도 순**으로 5박에 1일씩 배치 (2026-09-16 확정). |
| 안전 | 이충욱 = 안전관리 책임 — 매일 아침 브리핑에 당일 위험작업 안전교육(TBM) 포함(중량물, 진공/고압가스, 감전, 돔 회전부 고소작업). |
| 기록 | 이동주 = 기록 담당(사진·작업 로그, 매일 마감 시 configuration log 갱신) — site report 원자료. |

## 4. 확정 필요 사항

1. **온스카이 5개 과업의 중요도 순서**(틸트/회전각 → 마운트모델 → 초점코드수정 → 스크립트관측점검 → 파이프라인네트워크설정)는 2026-09-16 확정. 현지 기상·타겟 가시성으로 실제 순서 변경이 필요하면 이 표를 갱신한다.
2. 11-13 도착일 인원 배분(다인원 분담 병행)은 SSO 10-21~22 배분을 준용했으나, CTIO 현지 인원 지원 여부에 따라 조정 가능.
3. 홍성욱·김재우의 원격지원 방식(화상 연결/시차 등 구체 방법)은 추가 확정 필요.
